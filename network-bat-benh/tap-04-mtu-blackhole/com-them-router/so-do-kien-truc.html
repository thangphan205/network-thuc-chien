MTU Blackhole qua Router trung gian

scripts/1-normal-pmtud.sh ip route replace 172.28.42.0/24 dev eth1 mtu 1400
  • ping -s 1450 -M do → Frag needed and DF set (mtu = 1400)
  • Server nhận ICMP, tự hạ segment xuống ≤ 1360 byte
  • curl tải đủ 3093 bytes
scripts/2-fault-blackhole.sh iptables -I OUTPUT -p icmp -j DROP
  • Ping 64 byte: 0% loss — nhìn như mạng bình thường
  • Ping 1450 byte -M do: mất 100%, không ICMP báo về
  • curl: HTTP 200 nhưng 0 bytes, treo vô hạn
scripts/3-fix-mss-clamping.sh iptables -t mangle -A FORWARD -p tcp --tcp-flags SYN,RST SYN -j TCPMSS --clamp-mss-to-pmtu
  • Router rewrite MSS 1460 → 1360 ngay trong SYN / SYN-ACK
  • Không đụng cấu hình Client hay Server
  • Không gói nào vượt 1400 — curl tải đủ 3093 bytes
