Ping IP thì mượt, gõ tên miền thì chết — lab DNS

scripts/1-binh-thuong.sh dig web.lab.local · getent hosts web.lab.local
  • Query time ~0 ms — server sống, trả lời ngay
  • IP theo dig == IP theo getent — không ai chen ngang
  • Trang nhận được: SERVER MOI — đúng địa chỉ, đúng máy
scripts/2-resolver-khong-toi-duoc.sh /etc/resolv.conf → nameserver 172.28.6.99
  • dig: timed out sau ~2000 ms — không ai trả lời
  • curl exit 28, không phải 6 — dễ nhầm với "server chậm"
  • Query tới server = 0 — gói chưa từng tới DNS server
scripts/3-resolver-tu-choi.sh docker exec lab06-dns dns-stop
  • dig: connection refused sau ~17 ms — kernel trả ICMP port unreachable
  • curl exit 6 — khác KB2 (exit 28)
  • ping tới DNS vẫn thông — máy sống, dịch vụ chết
scripts/4-nxdomain.sh dig wed.lab.local # gõ nhầm web → wed
  • NXDOMAIN sau ~0 ms — server sống, đã trả lời dứt khoát
  • Log server ghi is NXDOMAIN — bằng chứng hai chiều
  • curl exit 6 giống hệt KB3 — chỉ dig tách được
scripts/5-forwarder-chet.sh server=/noi-bo.local/172.28.6.99 # thêm vào dnsmasq.conf
  • Màn hình dig giống KB2 từng chữ: timed out, ~2000 ms
  • Query tới server = 20 — gói ĐÃ tới, log ghi forwarded … to .99
  • Vùng lab.local vẫn chạy — khởi động lại DNS là chữa nhầm bệnh
scripts/6-tra-ip-sai.sh zone-hosts: 172.28.6.11 web.lab.local
  • dig xanh mướt: NOERROR — nhưng IP là .11, không phải .10
  • curl HTTP 200 từ SERVER CU — lỗi im lặng nhất
  • Câu phải hỏi: dig trả về đúng IP không?
scripts/7-hosts-de-dns.sh /etc/hosts (client): 172.28.6.11 web.lab.local
  • dig → .10 đúng, getent → .11 sai — hai công cụ lệch nhau
  • hosts: files dns — /etc/hosts đi trước DNS
  • Thủ phạm nằm trên máy client, DNS server vô can
scripts/8-cache-cu.sh nscd đã cache .10 → zone đổi web.lab.local sang .11
  • dig → .11 mới, getent → .10 cũ — /etc/hosts sạch
  • Restart ứng dụng vô ích — cache nằm trong nscd
  • Chữa ngay: nscd -i hosts — không cần đợi hết TTL
